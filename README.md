# Alphabet-to-Interger-
Program that initialises a map with corresponding numbers and letters and assigns the letter a numerical value from 1 to 26.

java Alphabet-to-Number Converter - Luka Lichailidis

Project Date: January 2025
Programming Language: Java
Project Type: Personal Programming Project

Project Overview

This project is a simple Java console-based application developed in January 2025 as part of my early programming experience.

The application allows a user to enter a single letter of the English alphabet and converts it into its corresponding numerical position (A = 1, B = 2, through to Z = 26).

Although relatively straightforward, this project helped me develop my understanding of fundamental Java programming concepts, including data structures, user input handling, conditional statements, and basic validation.

I have included this project in my GitHub portfolio to demonstrate my programming journey and showcase how my technical abilities have developed over time.
